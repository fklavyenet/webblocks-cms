# Brand identity

Use these three canonical product identity strings consistently across the CMS,
its public website, package registries, repository metadata, documentation, and
social metadata.

- Product name: **WebBlocks CMS**
- Official slogan: **A modern block-based CMS.**
- Package description: **A modern block-based CMS for content operations across multiple sites and locales.**

The slogan is the short brand line shown next to or below the product name. The
package description explains the product in registries, search metadata, and
other contexts where a fuller description is needed. Laravel remains an
important implementation and installation detail, but it is not part of either
canonical brand line.
