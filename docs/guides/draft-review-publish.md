# Draft, Review, And Publish

**Goal:** Move a page through the workflow without guessing what each button does.
**Time:** 3 minutes
**You need:** A page, and the permission for the step you are taking

## Steps

1. Open the page and go to the **Overview** tab. **Actions** shows only the moves available from the current state.
2. A **Draft** page offers **Submit for Review** and **Publish**.

> **Screenshot** `01-draft.png` — Overview of a draft page with both actions.
> Alt: Page overview showing draft status with submit for review and publish actions.

3. Select **Submit for Review** when someone else signs the work off. The page becomes **In Review**, and content editing is locked while it sits there.

> **Screenshot** `02-in-review.png` — The same page in review.
> Alt: Page overview showing in review status.

4. The reviewer publishes it, or sends it back with **Move Back to Draft**.
5. A **Published** page offers **Move Back to Draft** and **Archive**.

> **Screenshot** `03-pages-statuses.png` — The Pages list with pages in different states.
> Alt: Pages list showing draft, in review, published, and archived pages side by side.

## The Four States

| State | Visible to visitors | What it is for |
| --- | --- | --- |
| **Draft** | No | Work in progress. The default for anything new. |
| **In Review** | No | Finished, waiting for someone else. Content editing is locked. |
| **Published** | Yes | Live at its public address. |
| **Archived** | No | Taken down deliberately, kept rather than deleted. |

## Notes

- **In Review locks content editing on purpose.** If you need to change something, move it back to draft first — otherwise a reviewer is reading a moving target.
- If you cannot see **Publish**, your role prepares content but does not publish it. That is the system working, not a fault.
- Publishing the page does not publish its Shared Slots. See [Update A Shared Slot Safely](/guides/update-a-shared-slot).
- **Archive is not delete.** The page, its blocks, and its history stay; it simply stops being reachable. Deleting is a separate, destructive action.
- Every one of these moves is recorded — see [Revisions: See History And Restore](/guides/page-revisions).
