# Your Profile And Language

**Goal:** Update your own account details and switch the admin panel to your language.
**Time:** 1 minute
**You need:** Your own account

## Steps

1. Select your initials at the top right, then open **Profile**.
2. Under **Profile Information**, update your **Name**, **Email**, or **Interface language**, then select **Save Changes**. Leaving the language on **Use system default** means you follow whatever the installation is set to.

> **Screenshot** `01-profile.png` — The Profile screen with Profile Information and Change Password.
> Alt: Profile screen showing name, email, admin language, and the password section.

3. To change your password, fill in **Current password**, **New password**, and **Confirm new password** under **Change Password**, then select **Save Changes**.
4. For a quick language switch without opening Profile, use the language button in the top bar.

> **Screenshot** `02-language-menu.png` — The language menu open in the top bar.
> Alt: Admin top bar with the language menu open showing the available admin languages.

## Notes

- This changes the **admin interface** language only. It does not translate your site content, and visitors see nothing different. Translating pages is a separate job — see the Multiple Sites And Languages guides.
- The admin language is stored per user, so your colleagues keep theirs.
- The theme and accent controls next to the language button are personal display preferences too. They do not change the public site.
