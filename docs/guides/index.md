# Guides

Short, practical walkthroughs for everyday work in WebBlocks CMS. Each guide covers one task, in a few steps, with screenshots.

New here? Start with **Sign In To The Admin Panel** and follow the Next link at the bottom of each guide.

Looking for how a feature behaves rather than how to use it? That lives in the [reference documentation](/docs).

## Published

These become the cards in the index card grid, in this order. Card image, title, description, and link come from each guide's front matter.

### Series A — Get oriented

| Guide | Description |
| --- | --- |
| [Sign In To The Admin Panel](/guides/sign-in) | Open the admin panel, sign in, and find your way around the dashboard. |
| [The Admin Panel In Two Minutes](/guides/admin-tour) | What lives where in the sidebar, and which screens you will actually use. |
| [Page, Layout, Slot, Block](/guides/page-layout-slot-block) | The four words the CMS uses for everything, in plain language. |
| [Your Profile And Language](/guides/your-profile-and-language) | Change your name, email, password, and the language of the admin panel. |

### Series B — Your first page

| Guide | Description |
| --- | --- |
| [Create A Page](/guides/create-a-page) | Add a new page to a site and save it as a draft. |
| [Add A Heading And A Paragraph](/guides/add-heading-and-text) | Put your first words on a page using the Header and Plain Text blocks. |

All ten series are written: 43 guides. Two deliberate reductions along the way — previewing a page lives inside [Publish A Page](/guides/publish-a-page) rather than as its own guide, and the structured-content series is one guide because the FAQ, Accordion, and Tabs block types are not part of this installation.
