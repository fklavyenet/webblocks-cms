# The Admin Panel In Two Minutes

**Goal:** Know which screen to open for which job.
**Time:** 2 minutes
**You need:** Access to the admin panel — see [Sign In To The Admin Panel](/guides/sign-in)

## Steps

1. Open the **Dashboard**. The Overview panel counts your pages, blocks, and media, and **Quick actions** links straight to the jobs you do most.
2. Open **Pages**. This is where you spend most of your time: every page on the site, its status, and the New Page button.
3. Open **Media**. Every image, video, and document you upload lives here once and can be reused on any page.
4. Glance at the rest of the sidebar. You do not need it today, but knowing it exists saves you hunting later.

## What Each Section Is For

| Section | Use it when you want to |
| --- | --- |
| **Dashboard** | See what changed and jump to a common task |
| **Pages** | Create, edit, preview, and publish pages |
| **Blocks** | Find a block across the site without opening its page |
| **Shared Slots** | Edit an area that repeats on many pages, such as the header |
| **Navigation** | Change the menus visitors click |
| **Media** | Upload and organise images, video, and documents |
| **Contact Messages** | Read what visitors sent through a contact form |
| **Engagement** | Moderate comments and ratings |
| **System / Maintenance** | Site setup, users, backups, updates — operator territory |

## Notes

- Your role decides what you see. Fewer sidebar items is not a fault; it means those areas are not yours to change.
- On an installation with several sites, most screens work on one selected site at a time. Check the site before you create anything.
