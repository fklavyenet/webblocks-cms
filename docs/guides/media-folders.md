# Organise Media In Folders

**Goal:** Group media so you can still find things when the library grows.
**Time:** 2 minutes
**You need:** Media access

## Steps

1. Open **Media** and select **New Folder**.
2. Give it a **Name**. The **Slug** fills itself in, and **Parent Folder** nests it under an existing one if you need a level down.
3. Select **Save**.

> **Screenshot** `01-new-folder.png` — The New Folder dialog with a name filled in.
> Alt: New folder dialog showing name, slug, and parent folder fields.

4. To move a file, open it from the library and set **Folder** on its edit screen, then **Save changes**.
5. Back in the library, the folder chips above the list filter it. **All folders** shows everything again.

> **Screenshot** `02-folders.png` — The library with a folder chip and a file filed under it.
> Alt: Media Library showing folder chips and a document assigned to the Studio documents folder.

## Example

```text
Studio documents   ← rate cards, contracts, briefs
Journal            ← images used in journal posts
Brand              ← logos and identity assets
```

## Notes

- **Folders are for finding, not for permissions.** Filing something away does not restrict who can see or use it.
- Moving a file between folders does not break any block that uses it. The block points at the file, not at its location.
- Do not mirror your page structure in folders. Media gets reused across pages, and a folder tree that copies the site becomes wrong the first time you reuse an image.
- Three to eight folders at the top level is usually enough. Beyond that, search and the **Kind** filter find things faster than clicking through a tree.
- The **Usage** column tells you where a file is used, which is what you actually need before deleting anything.
