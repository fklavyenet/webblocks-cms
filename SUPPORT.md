# Support

Use the [GitHub issue tracker](https://github.com/fklavyenet/webblocks-cms/issues) for reproducible WebBlocks CMS bugs and package feature requests. Include the package version, Laravel and PHP versions, expected behavior, actual behavior, and a minimal reproduction without credentials or private application data.

Installation and integration questions should first be checked against [README.md](README.md), [UPGRADING.md](UPGRADING.md), and the public [documentation](docs/). General project information is available at [fklavye.net](https://fklavye.net).

Do not report security vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) instead.
