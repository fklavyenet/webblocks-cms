# Security Policy

Do not open public issues for suspected vulnerabilities in the WebBlocks CMS package.

Contact the maintainer privately through [fklavye.net](https://fklavye.net). Include the affected version and configuration, impact, reproducible steps, and any proposed remediation. Test only systems you own or have explicit permission to assess.

The package repository's current code, installation/update flow, Internal Content API, and CMS-owned admin/public surfaces are in scope. Third-party dependency vulnerabilities should also be reported to their upstream projects.

No response time, release cadence, or GitHub private-vulnerability-reporting availability is promised by this document.
