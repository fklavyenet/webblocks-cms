# WebBlocks CMS Starter Stubs

These files document the future starter-project shape for package-based installs.

- `composer.json.stub` shows the intended package-consumer Composer boundary.
- `env.example.stub` lists the package transition controls a starter should expose.
- Runtime CMS code should come from `fklavyenet/webblocks-cms`.
- Install-owned customization should stay in the consuming Laravel project.
